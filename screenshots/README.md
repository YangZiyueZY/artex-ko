# 截图说明（Screenshots）

中文 · [한국어](README.ko.md)

本文件夹里放着两套彼此不同的画面集合。为了不让它们看起来混在一起，先说明各是哪一边。

- **`en/`：默认英文界面下捕获的 ARTEX 真实画面。** 这是面向英文读者的交付画面，由英文主文档 [`../README.en.md`](../README.en.md) 以及韩语·西班牙语·日语版主文档使用。只想看交付用的英文画面，请打开 [`en/`](en/) 文件夹。
- **根目录的 `*.png`：上游原版（中文版）的界面截图。** 它们**原样保留**，以便与上游仓库 1:1 对照，并由简体中文主文档 [`../README.md`](../README.md) 引用。
- **`wx.png`：上游原作者的微信（WeChat）公众号宣传图。** 一并原样保留，与本 fork 无关。

也就是说，在根目录先看到的中文画面是出于上游保留；**面向英文读者的交付画面在 [`en/`](en/) 里。** 本仓库为什么要把原版画面与本地化画面并排保留（本地化透明度·上游对照），与防御·检测的定位是同一脉络，详细背景见根目录 README。
